Tools

Free, browser-based utilities for NMR, spectroscopy and materials chemistry. Everything runs in your browser; no data is uploaded.

  • NMR Frequencies

    Interactive plot of the Larmor frequency of NMR-active nuclides versus applied magnetic field, with a downloadable table of gyromagnetic ratios.

  • Periodic Table

    Interactive periodic table with searchable element data.

  • Curie-Weiss

    Interactive Curie-Weiss law plot: vary the spin, Weiss constant and temperature range, and overlay several curves.

  • Unit Conversion

    Convert between energy, frequency and wavelength units commonly used in spectroscopy.

  • CFSE

    Crystal field splitting diagrams and crystal field stabilisation energies for d-electron configurations in different geometries.

  • XRD Utilities

    Convert between d-spacing, 2θ and Q, and compute reflections from lattice parameters and Miller indices.

Software

openNMR

openNMR is a free, open-source, vendor-agnostic desktop application for processing, fitting, integrating and simulating NMR data, with no scripting needed. It reads raw data from Bruker TopSpin, Varian/Agilent, JEOL Delta, Magritek Spinsolve, X-Pulse and SIMPSON. I maintain the project.

Website and tutorials · install with pip install opennmr (MIT licence)
